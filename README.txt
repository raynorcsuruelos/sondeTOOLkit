SONDE TOOLKIT V4 PWA

Upload all five web files (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to the root of a GitHub Pages repository. Keep filenames unchanged. Open the HTTPS Pages URL in Chrome on Android, visit once online, then use browser menu > Add to Home screen / Install app. Open once online before testing offline. The original standalone HTML remains available separately.

IMPORTANT: PWA installation and service workers require HTTPS or localhost, not file://. Browser storage is tied to the site origin; local HTML data does not automatically migrate to a GitHub Pages URL. Export/import backup before switching. kPod PDF folder access may require reselecting folders, and external PDF readers are browser dependent.
