Sonde Toolkit V16.10 PWA

Upload the CONTENTS of this folder (index.html, sw.js, manifest.webmanifest and icons/) to a GitHub Pages repository root or another HTTPS static host. Enable GitHub Pages, visit the HTTPS URL in Chrome or Edge, then choose Install app / Add to Home screen.

Opening index.html directly as a file is still supported for the standalone toolkit, but PWA installation and service worker offline caching require HTTPS or localhost.

Folder permissions and browser IndexedDB data are specific to each browser origin; installing at a new URL does not automatically migrate data from an old URL. Back up your saved records before changing the host URL. Folder access may need to be reconnected.
